# Project instructions
Read docs/PROJECT_PLAN.md before continuing work.
Use Next.js App Router and strict TypeScript. Keep Shopify credentials server-only.
Current scope: storefront design, demo catalog, interactive editor prototype, read-only Storefront API preparation.
The editor uses logical preview pixels, not validated print measurements. Do not label its output print-ready.
Keep saved designs local to the browser until backend storage is explicitly scoped.
Do not implement payment, checkout, or printer integration without a new user request.
Do not silently replace failed live Shopify requests with demo data.
Run lint, typecheck, test, and build for relevant changes.
